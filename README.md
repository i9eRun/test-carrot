# 동네상점

모바일과 데스크톱 브라우저에서 동네 중고거래를 체험하는 웹 프로토타입입니다. 성수동 예시 매물 3개로 시작합니다.

## 실행

Python 3가 설치된 환경에서 저장소 폴더를 열고 실행합니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 [동네상점 열기](http://127.0.0.1:8000)를 선택합니다.

## 사용하기

- 검색창에 제목이나 설명에 포함된 단어를 입력하거나 카테고리로 매물을 좁힙니다.
- 매물 카드를 선택하면 사진, 가격, 설명을 볼 수 있습니다.
- **판매글 쓰기**에서 사진 한 장과 제목, 가격, 카테고리, 설명을 입력합니다. 가격을 0원으로 입력하면 나눔으로 표시됩니다.
- 등록한 글은 이 브라우저의 로컬 저장소에 남습니다. 계정, 사용자 간 매물 공유, 채팅은 별도의 서버가 필요한 후속 기능입니다.

예시 사진은 Unsplash의 [의자](https://images.unsplash.com/photo-1503602642458-232111445657), [카메라](https://images.unsplash.com/photo-1516035069371-29a1b244cc32), [자전거](https://images.unsplash.com/photo-1485965120184-e220f721d03e) 이미지를 사용합니다.
